`raw/` = UCI Bike Sharing Dataset (Fanaee-T, H., 2013, DOI 10.24432/C5W894), https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset, licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Unmodified; processing is done in code (`bike.py`).

The files are included in this repo. To download them again (run from `data/`): `curl -sSL --create-dirs -o raw/bike.zip "https://archive.ics.uci.edu/static/public/275/bike+sharing+dataset.zip" && unzip -o raw/bike.zip -d raw && rm raw/bike.zip`
